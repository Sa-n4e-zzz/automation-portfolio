02

Фотоотчёты по объектам

Мобильный инструмент для сбора фотоотчётов на объектах, разработанный самостоятельно. Данные хранятся локально, на устройстве пользователя.

01

План

Письма отбираются по теме и отправителю. Из вложений Excel/CSV загружается и проверяется план.

02

Объект

Объект выбирается из плана — открывается его карточка для дальнейшей фотофиксации.

03

Фото

Фото с камеры или из галереи, подписи и необязательные отметки освидетельствования.

Результат: документ Word — по объекту, дню или периоду. Все данные хранятся локально, на устройстве пользователя.

Раскрыть кейс: задача, мой вклад, сценарий

Задача

Собрать в одном мобильном процессе весь путь от письма с плановыми данными до готового отчётного документа по объекту.

Мой вклад

Спроектировал и реализовал инструмент самостоятельно — от загрузки данных до формирования итогового файла.

Сценарий

Отбор письма по отправителю → разбор Excel/CSV-вложения → проверка и импорт плана → выбор выезда и объекта → пользователь добавляет фото с камеры или из галереи, подписывает их и при необходимости ставит отметку освидетельствования → итоговый документ Word формируется по объекту, дню или периоду. Все данные приложения хранятся локально, на устройстве пользователя.

03

VPN — личный проект

Небольшой семейный сервис для доверенного круга пользователей: управление устройствами и доступом, контроль состояния сервера. Некоммерческий проект, разработан самостоятельно для семьи.

Три задачи панели

  • Устройства и выданные доступы
  • Выдача и отключение доступа
  • Мониторинг и диагностика сервера
Раскрыть кейс: задача, мой вклад, сценарий

Задача

Требовался удобный способ выдавать и отзывать доступ ограниченному кругу пользователей и контролировать работоспособность сервера из единого интерфейса.

Мой вклад

Разработал панель самостоятельно: реестр устройств, выдача и отключение доступа, мониторинг состояния сервера и базовая диагностика.

Сценарий

Новое устройство регистрируется в панели → выдаётся доступ → при необходимости доступ отключается вручную → состояние сервера и диагностика отображаются в отдельном разделе.

04

Инструменты

Прикладные разработки, закрывающие конкретные задачи в закупочном и производственном документообороте.

01

Конструктор спецификаций

Совместная разработка. Табличная выгрузка (XLSX/XLS/XLSB/CSV) размечается на поля и правила, задаётся группировка — на выходе спецификации и дополнительные соглашения в Excel и PDF.

Правила, форматы, мой вклад

Поддержаны семь типов правил обработки поля: копирование, фиксированное значение, ВПР, расширенный ВПР, формула, условное и комбинированное правило. Отдельно можно сформировать сводный реестр по всем документам.

Участвовал в реализации и тестировании, вносил доработки по замечаниям, подготовил инструкцию для пользователей и сопровождал программу.

Выгрузка → поля и правила → группировка → спецификации и допсоглашения (Excel/PDF)

02

Обработка входящих PDF-спецификаций

Самостоятельная разработка. Из текстового PDF извлекаются позиции и условия, сопоставляются с договорными реквизитами по таблице соответствия — формируется исходящая спецификация.

Логика обработки, мой вклад

Цены пересчитываются по заданному коэффициенту, реквизиты подставляются из таблицы соответствия. Позднее движок обработки перенесён в веб-модуль платформы.

Текстовый PDF → позиции и условия → таблица соответствия реквизитов → пересчёт по коэффициенту → исходящая спецификация

03

Excel/VBA-инструменты

Набор макросов для рутинных операций с табличными данными.

  • Сведение выгрузок из разных систем
  • Сопоставление данных между источниками
  • Очистка и объединение повторяющихся записей
  • Формирование реестров и отчётности по заданным правилам

Стек: Python, PyQt5, pdfplumber, Excel. В разработке использую ИИ-инструменты как часть рабочего процесса — для ускорения рутинных шагов и первичной проверки решений; итоговый результат проверяю и дорабатываю сам.
