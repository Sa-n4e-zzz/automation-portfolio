Небольшие инструменты для повседневных задач компании.

Раздел 01

Таблицы и реестры

  1. 01

    Объединение таблиц Первый шаг

    Объединяет однотипные файлы от разных источников в одну таблицу без ручного копирования.

  2. 02

    Реестр под формат заказчика

    Собирает данные в таблицу со столбцами и порядком, которые требует конкретный клиент.

  3. 03

    Единые названия и форматы данных

    Приводит города, контрагентов и даты к единому виду по согласованному словарю соответствий.

  4. 04

    Разбивка сводной таблицы

    Делит общий реестр на отдельные файлы по клиенту или периоду одним запуском.

Раздел 02

Подготовка документов

01

Заявка на перевозку из карточки Первый шаг

Формирует готовый документ-заявку по данным карточки рейса без повторного набора текста.

02

Генератор коммерческих предложений

Собирает коммерческое предложение по утверждённой ставке и шаблону из введённых параметров.

03

Пакет документов по рейсу

По одной строке таблицы создаёт сразу несколько связанных документов, например заявку и счёт-черновик.

04

Проверка обязательных полей документа

Перед печатью проверяет, что нужные поля заполнены, и указывает пропуски.

Раздел 03

Проверка данных

  1. 01

    Сверка двух реестров рейсов Первый шаг

    Сопоставляет список рейсов из одного источника со списком из другого и показывает расхождения.

  2. 02

    Сверка реквизитов контрагентов

    Сравнивает сведения из двух таблиц и показывает несовпадения для проверки сотрудником.

  3. 03

    Поиск возможных дублей документов

    Находит возможные совпадения по номеру, дате и контрагенту по реестру документов и выводит кандидатов для проверки.

  4. 04

    Сравнение сумм по условиям

    Сопоставляет согласованные условия рейса с фактическими доплатами. Только список расхождений, без выводов о задолженности.

Раздел 04

Архив и комплекты

01

Сортировка документов по номеру и дате Первый шаг

Переименовывает и раскладывает копии документов (оригиналы сохраняются) по номеру рейса, дате или контрагенту.

02

Проверка комплекта документов

Проверяет наличие файлов по рейсу в архиве (не содержание и подписи) и выводит список недостающих.

03

Сборка комплекта клиенту за месяц

Собирает документы и реестр по одному клиенту за выбранный период в один пакет.

04

Поиск файла по номеру или дате

Находит документ в архиве без ручного перебора папок.

Раздел 05

Рейсы и задания

  1. 01

    Список заданий на день Первый шаг

    Формирует перечень рейсов на выбранную дату из доступной выгрузки для утренней проверки.

  2. 02

    Журнал отклонений и простоев

    Фиксирует введённые сотрудником задержки, простои и повреждения в единой форме учёта.

  3. 03

    Контроль дат по рейсам

    Показывает рейсы, где согласованная дата приближается или прошла, для ручного контроля.

  4. 04

    Привязка фото к рейсу

    Прикрепляет фотографии и материалы к рейсу для последующего поиска. Доступы для совместной работы нескольких сотрудников продумываются отдельно.

Раздел 06

Коммерческая работа

01

Сравнение предложений перевозчиков Первый шаг

Сопоставляет несколько предложений по одинаковым условиям рейса в одной таблице.

02

История ставок по направлениям

Собирает данные по прошлым сопоставимым рейсам, чтобы видеть диапазон ставок.

03

Учёт отправленных предложений

Ведёт реестр предложений, вопросов клиента и даты следующего контакта.

04

Тарифный справочник условий клиентов

Хранит версии согласованных условий и тарифов для быстрого расчёта.

Раздел 07

Отчёты руководителю

  1. 01

    Сводка по статусам и отклонениям Первый шаг

    Собирает краткий отчёт о текущих статусах рейсов и зафиксированных отклонениях за период.

  2. 02

    Объём перевозок по клиентам и направлениям

    Формирует отчёт по клиентам, направлениям и периодам на основе накопленных данных.

  3. 03

    Открытые задачи по документам

    Показывает открытые задачи по документам и ответственным из заполненного реестра.

  4. 04

    План-факт по показателям

    Сравнивает плановые и фактические значения по согласованным показателям.

Раздел 08

Помощники и дальнейшее развитие

01

Справочный бот по шаблонам

Выдаёт ссылку на нужный утверждённый шаблон по ключевому слову, без использования ИИ.

02

Уведомления об обновлении шаблонов

При утверждении новой версии в каталоге сообщает, какой документ использовать.

03

Черновики сопроводительных писем

ИИ готовит текст к выбранному комплекту документов; сотрудник проверяет его перед отправкой.

04

Поиск по архиву с указанием источника

ИИ ищет информацию в разрешённых документах архива с указанием источника ответа. Направление для дальнейшего развития, не первый пилот.
